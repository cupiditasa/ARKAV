# تامینو / Zand

این پروژه سایت عمده‌فروشی بازرگانی زند را در مسیر `arkav.ir/zand` منتشر می‌کند. فایل‌های عمومی زیر `public/zand/` و Worker با نام `taminu-zand` سرو می‌شوند.

## قیمت و محصولات

Worker هر روز ساعت ۰۱:۰۰ UTC قیمت پایه را از API عمومی دست‌اول و قهوه‌عمده دریافت و در KV با binding به‌نام `PRICES` نگه می‌دارد. قیمت مشتری بر پایهٔ قیمت تازه و درصد سود مؤثر محاسبه می‌شود: محصول ← گروه ← تنظیم عمومی. نرخ‌های مرجع قدیمی‌تر از ۳۶ ساعت در فروشگاه قابل‌نمایش نیستند. قیمت دستی مدیر منقضی نمی‌شود و کالای استعلامی قیمت قطعی نشان نمی‌دهد.

پایگاه D1 ساخته و migration اولیه اجرا شده است. نخستین درخواست کاتالوگ، محصولات موجود را به‌صورت خودکار در D1 ثبت می‌کند؛ پس از آن، وضعیت فروش و اطلاعات کالا از D1 خوانده می‌شود و همگام‌سازی روزانه از همان فهرست استفاده می‌کند.

## حساب مشتری و مدیریت

- ثبت‌نام مشتری با نام کاربری، گذرواژه و تکرار آن انجام می‌شود؛ حساب نیاز به تأیید دستی یا OTP ندارد.
- پس از ورود اولیه، ثبت نام، نام خانوادگی و شمارهٔ تماس لازم است. نام کاربری و شمارهٔ نرمال‌شده در پایگاه داده یکتا هستند.
- مشتری می‌تواند آدرس ذخیره کند، درخواست سفارش ثبت و پیگیری کند، و به پشتیبانی پیام بدهد.
- مدیر می‌تواند کالا اضافه/ویرایش/بایگانی کند، فروش را روشن یا خاموش کند، وضعیت سفارش را تغییر دهد و درصد سود ۵ تا ۳۰ را برای فروشگاه، گروه یا کالا تنظیم کند.
- APIها نقش مشتری و مدیر را در سمت Worker کنترل می‌کنند. گذرواژه با PBKDF2 ذخیره و نشست با کوکی امن سمت سرور مدیریت می‌شود.
- مدیر اول از مسیر «راه‌اندازی مدیر اول» در `/zand/admin/` ساخته می‌شود؛ کلید `ADMIN_SETUP_SECRET` باید فقط در Secrets سرویس ثبت شود و داخل مخزن قرار نگیرد.

## راه‌اندازی Cloudflare برای قابلیت‌های پایگاه‌داده

پایگاه D1 با binding نام `DB` به Worker وصل است و migration اولیه اجرا شده؛ ثبت‌نام مشتری و API حساب‌ها در دسترس‌اند. برای ساخت مدیر اول، مقدار `ADMIN_SETUP_SECRET` را به‌عنوان Secret در Worker تنظیم کنید؛ تا پیش از آن، راه‌اندازی مدیر عمداً بسته می‌ماند. مقدار Secret را در مخزن یا README ننویسید.

دامنهٔ مقصد `zandbazar.ir` هنوز ثبت نشده. تا زمان ثبت و اتصال DNS، صفحه‌های حساب و مدیریت روی نشانی `workers.dev` در دسترس خواهند بود؛ بعد از آماده‌شدن دامنه باید Worker به همان دامنه متصل و نشانی‌های پنل به دامنهٔ اصلی تغییر داده شوند.
