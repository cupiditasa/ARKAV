# تامینو /zand

این پروژه سایت عمده‌فروشی بازرگانی زند را روی مسیر arkav.ir/zand منتشر می‌کند. فایل‌های عمومی زیر public/zand/ قرار دارند و Worker با نام taminu-zand درخواست‌ها را سرو می‌کند.

## همگام‌سازی قیمت

Worker هر روز ساعت ۰۱:۰۰ به وقت UTC از API عمومی دست‌اول و API فروشگاه قهوه عمده قیمت می‌گیرد و نتیجه را در Cloudflare KV نگه می‌دارد. نرخ قابل‌نمایش برابر قیمت مرجع × ۱٫۱۰ است. هر کارت زمان آخرین دریافت نرخ همان کالا را نشان می‌دهد.

قیمت‌هایی که بیش از ۳۶ ساعت تازه نشده باشند، به شکل «استعلام قیمت روز» نمایش داده می‌شوند. کالاهایی که با شناسهٔ تصویر یا نام دقیق به مرجع وصل نشوند نیز قیمت ساختگی یا قدیمی نمی‌گیرند و استعلامی می‌مانند. همگام‌سازی از یک Cron Trigger روزانه استفاده می‌کند.
