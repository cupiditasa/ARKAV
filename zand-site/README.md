# تامینو /zand

این پوشه یک پروژه مستقل برای انتشار سایت روی مسیر `arkav.ir/zand` است. فایل‌های عمومی زیر `public/zand/` نگه‌داری می‌شوند تا ساختار URL با مسیر دامنه هماهنگ باشد.

## پیش‌نیاز انتشار

- دسترسی به ریپوی اصلی آرکاو و محدوده DNS دامنه `arkav.ir` در Cloudflare.
- تایید اینکه Worker یا Pages فعلی روی مسیر `arkav.ir/zand*` تداخلی ندارد.
- نصب و ورود Wrangler از داخل همین پروژه.

قیمت‌ها تا اتصال خوراک قیمت تامین‌کنندگان، به‌صورت استعلام نمایش داده می‌شوند. قیمت مشتری پس از دریافت قیمت پایه باید از فرمول `قیمت تامین × 1.10` محاسبه شود.
