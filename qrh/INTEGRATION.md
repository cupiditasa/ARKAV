# راهنمای افزودن صفحهٔ QRH به سایت ARKAV

این پوشه یک صفحهٔ مستقل و آماده برای مسیر زیر است:

```text
https://arkav.ir/qrh/
```

## روش ادغام

محتویات این پوشه را در پروژهٔ اصلی سایت داخل مسیر `qrh/` قرار دهید. فایل‌ها باید در نهایت این ساختار را داشته باشند:

```text
qrh/
  index.html
  styles.css
  app.js
  manifest.json
  sw.js
  QRH_sample_100.pdf
```

سپس در منوی سایت اصلی این لینک را اضافه کنید:

```html
<a href="/qrh/">کتاب QRH</a>
```

## نکات مهم برای هوش مصنوعی ادغام‌کننده

- این صفحه مستقل است و نباید CSS یا JavaScript سایت اصلی را تغییر دهد.
- نسخهٔ عمومی فقط شامل `QRH_sample_100.pdf` (۱۰۰ صفحهٔ نمونه) است؛ PDF کامل نباید در `/qrh` منتشر شود.
- مسیر خرید داخل `app.js` به PayPing زیر متصل است:
  `https://payping.net/d/Kwrq`
- اگر سایت build می‌شود، پوشهٔ `qrh` باید بدون تغییر در خروجی نهایی build کپی شود.
- اگر سایت از router استفاده می‌کند، برای `/qrh/` یک مسیر static یا fallback جدا در نظر بگیرید.
- سرویس‌ورکر فقط روی HTTPS کار می‌کند؛ پس سایت نهایی باید با HTTPS منتشر شود.
- PDF داخل این صفحه قابل مشاهده است، اما چون فایل همراه صفحه منتشر می‌شود، حفاظت کامل در برابر دانلود ندارد.

## متن آماده برای دادن به هوش مصنوعی سایت

```text
یک صفحهٔ مستقل با مسیر /qrh/ به سایت اضافه کن.
محتویات پوشهٔ qrh را بدون تغییر ساختاری داخل خروجی سایت قرار بده.
صفحه باید با مسیر https://arkav.ir/qrh/ باز شود.
در منوی سایت اصلی یک لینک با عنوان «کتاب QRH» به /qrh/ اضافه کن.
استایل و JavaScript این صفحه را از سایت اصلی جدا نگه دار.
مطمئن شو مسیر PDF نمونه به‌صورت نسبی و برابر با QRH_sample_100.pdf باقی بماند.
دکمهٔ خرید باید به https://payping.net/d/Kwrq متصل باشد.
در صورت وجود router، این مسیر را به‌عنوان static page ثبت کن و اجازه نده fallback سایت اصلی محتوای qrh را جایگزین کند.
```
